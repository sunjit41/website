## ⚙️ Installation & Setup
To run this project locally:
1. Clone the repository.
2. Navigate to the `classes/` directory.
3. Duplicate the `config.sample.php` file and rename the copy to `config.php`.
4. Edit `config.php` and fill in your local database credentials.
